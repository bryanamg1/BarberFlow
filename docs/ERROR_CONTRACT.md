# BarberFlow — Error Contract

Version: 1.0  
Status: APPROVED

Normalized shape:

```ts
interface DomainError {
  code: ErrorCode
  message: string
  metadata?: Record<string, unknown>
}
```

UI never displays raw SQL/Postgres/Supabase internals.

## Auth/access
AUTH_INVALID_CREDENTIALS, AUTH_SESSION_EXPIRED, AUTH_UNAUTHORIZED, AUTH_PROFILE_NOT_FOUND, BUSINESS_MEMBERSHIP_NOT_FOUND, BUSINESS_ACCESS_DENIED.

## Appointments
APPOINTMENT_CONFLICT, APPOINTMENT_OUTSIDE_BUSINESS_HOURS, APPOINTMENT_BUSINESS_CLOSED, APPOINTMENT_NOT_FOUND, APPOINTMENT_ALREADY_COMPLETED, APPOINTMENT_CANCELLED, INVALID_APPOINTMENT_STATUS.

## Clients
CLIENT_NOT_FOUND, CLIENT_INACTIVE.

## Products/inventory
PRODUCT_NOT_FOUND, PRODUCT_INACTIVE, INSUFFICIENT_STOCK, INVALID_STOCK_ADJUSTMENT, STOCK_OPERATION_FAILED.

## Sales/checkout
SALE_NOT_FOUND, SALE_ALREADY_COMPLETED, SALE_ALREADY_VOIDED, INVALID_SALE_ITEM, INVALID_DISCOUNT, CHECKOUT_FAILED, DUPLICATE_OPERATION.

## Payments
INVALID_PAYMENT_METHOD, INVALID_PAYMENT_AMOUNT, PAYMENT_TOTAL_MISMATCH.

## Purchases
PURCHASE_NOT_FOUND, PURCHASE_ALREADY_COMPLETED, INVALID_PURCHASE_ITEM, PURCHASE_FAILED.

## Expenses
EXPENSE_NOT_FOUND, INVALID_EXPENSE_AMOUNT, DUPLICATE_PURCHASE_EXPENSE.

## Generic
VALIDATION_ERROR, NOT_FOUND, UNAUTHORIZED, FORBIDDEN, DATABASE_ERROR, NETWORK_ERROR, UNKNOWN_ERROR.

Important metadata examples:
- APPOINTMENT_CONFLICT: requestedStart, requestedEnd, conflictingAppointmentId.
- INSUFFICIENT_STOCK: productId, productName, requested, available.

RPC exceptions may force rollback, but repository/service layers must map them to normalized DomainError before UI consumption.
